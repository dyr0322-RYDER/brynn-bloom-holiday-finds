HOLIDAY HOSTING / THE EASY DIY EDIT

Elegant DIY Christmas Place Settings Using Dishes You Already Own

Set a thoughtful holiday table with your existing white or neutral dishes, an ivory cloth napkin, a little evergreen greenery and a burgundy velvet bow. Add woven chargers and gold flatware only if you already have them or want an optional upgrade.

THE LITTLE TABLE TRANSFORMATION

Set each place in five steps

  1. Layer your plates. Start with a woven charger or placemat if you have one, then center your everyday dinner plate. Add a salad plate if your meal calls for it; a single plate is lovely too.
  2. Fold your napkin. Fold a clean ivory or neutral cloth napkin into a long rectangle and place it down the center of the plate, with the folded end toward your guest.
  3. Add greenery. Lay a small faux evergreen sprig along the napkin. Add a few faux red berries for color. Keep all decorations separate from food and remove them before eating.
  4. Tie a velvet bow. Wrap narrow burgundy velvet ribbon around the napkin and greenery, then tie a generous bow. Make sure it can be untied easily without tugging the place setting.
  5. Add a name card. Write each guest’s name on a small kraft tag and tuck it under the ribbon or tie it loosely with twine. Repeat the same arrangement for every seat for a coordinated look.

Keep the cost down

Start with what you own: dishes, drinking glasses and everyday flatware. The details that create this look are the folded napkin, greenery, burgundy ribbon and handwritten name card. Woven chargers, gold flatware, pinecones and candleholders are optional extras—not required purchases.

If you use real greenery, identify it first: some evergreens and berries can be toxic or irritating. Faux stems are a simple option for reusable place settings. Keep décor and ribbons away from flames, and use flameless candles where practical.
